# FHD_FON — configuration source snapshot

Комплект исходников конфигураций для GitHub/Nexus. Все 13 файлов присланного архива восстановлены из редактируемых исходников побайтово точно. **В присланном архиве отсутствуют сами изображения фонов и файлы PKG. Этот комплект не является полной установочной сборкой графического мода.** Вручную создавать `.rson`, `.scr` или декодировать `.dat` не требуется.

## Scope for Nexus review

This repository recovers all code and configuration actually present in `FHD_FON.rar` (14909 bytes). It contains three modules: `FHDBG`, `FHDDynamicBG`, and `FHDNightBG`. The uploaded archive has eight binary DAT configurations and five text files. All thirteen can be rebuilt without the original archive or prebuilt DAT inputs.

The archive contains **empty directories** named `FHDBG/FHDBG.pkg` and `FHDNightBG/FHDNightBG.pkg`. They are not resource-package files. The `FHDDynamicBG/DATA/CityBG`, `GovBG`, and `RuinsBG` directories are empty too. No GI images, real PKG archives, SCR files or DLLs were supplied. Original background artwork cannot be reconstructed from resource names alone. This repository therefore does not claim to provide the complete graphical mod or its asset sources.

## Source layout

- `source/<module>/CFG/*.json`: editable lossless DAT source trees. They preserve parameter order, duplicate names, sorting metadata and encryption seed.
- Matching UTF-8 `.txt` files: readable views of the same configurations, including the actual inline scripting code. These are review aids; the builder consumes JSON.
- `source/<module>/ModuleInfo.txt` and `INSTALL.TXT`: editable UTF-8 text, converted back to original encodings during build.
- `tools/dat_codec.py`: standalone DAT reader/writer using Python's standard library.
- `tools/audit.py`: background resource and dependency checks.
- `original-file-sha256.json`, `text-encodings.json`, `source-provenance.json`: original hashes, encoding descriptors and recovery scope.
- `build-verification.json`: the actual local rebuild and audit results.

There is no separate compiled SCR in this upload. The game-event code is embedded in the decoded `FHDDynamicBG` configuration, particularly the Rus/Eng Lang trees; it is included as editable JSON strings and readable text. Adding invented SCR/RSON files would not reproduce the supplied mod.

## Build instructions

Use Python 3.12. No pip packages, game files, Windows tools, compiler downloads or network services are required. Run from the repository root:

```sh
python3 build.py --strict-original
```

On Windows with Python 3.12 installed:

```bat
py -3.12 build.py --strict-original
```

The verified environment was CPython 3.12.14 with zlib 1.2.13 on Linux. Windows execution and in-game behavior were not tested. `--strict-original` checks the file list and all thirteen SHA-256 values, failing on any mismatch. All eight regenerated DATs also are decoded again from the regenerated bytes and compared with their source trees.

Outputs:

```text
dist/FHD_FON_CONFIGS_ONLY_FROM_SOURCE.zip
dist/build-report.json
```

The ZIP preserves the original `Mods/FHD_MODS/FHD_FON/<module>/` paths and includes only the thirteen supplied runtime configurations/text files. It is intended for reproducing and reviewing this snapshot; it does not supply the missing graphics. Do not treat it as a complete standalone installation.

To explicitly require a complete mod, run:

```sh
python3 build.py --strict-original --require-complete
```

For this incomplete input the command writes the audit report and deliberately exits with failure without producing a complete-mod ZIP. GitHub Actions runs the configuration rebuild and publishes its outputs as review artifacts. The workflow itself has not been executed on GitHub in this preparation.

## Verified result and original findings

All **13/13** supplied runtime files rebuilt byte for byte, including all eight DAT files. No precompiled runtime files are used as build inputs, and no production behavior was changed.

The original CacheData trees contain 485 background aliases pointing to 409 distinct normalized paths. Of these, 357 distinct paths belong to this mod; the other 52 alias references point to optional third-party packs. None of their image bytes is present in the uploaded archive. The report separates these cases instead of treating optional packs as newly introduced failures.

The original configurations also contain:

- A mutual dependency: `FHDBG -> FHDDynamicBG -> FHDBG` in ModuleInfo.
- Ten references from this mod's catalog to aliases absent from the supplied CacheData. Eight are night government paths using a dot after `FHDNightBG` where the cache names use an underscore. One FHDBG path contains `FHDBG.DenBG_002`; the other is the base `ruin_DB` path.
- One additional unmatched reference gated by the optional PolarStationsBG pack. Its namespace uses `DynamicBG_ruin` rather than the `FHDDynamicBG_ruin` namespace defined in the supplied cache.

These are static findings in the original upload. They are documented in full in the report and preserved so reviewers can verify exact reproduction. Runtime consequences, optional-pack resolution and dependency handling require the actual game and were not tested here.
